# 특허 검토 초안 보조 도구

**비공식 도구입니다. 개인이 만든 보조 도구이며 어떤 기관의 프로그램도 아닙니다. 결과는 법적 판단이 아니고, 사람이 확인해야 하는 초안입니다.**

Codex 프로그램에서 이 폴더를 열고 채팅으로 말하면, Codex 가 폴더 안의 스크립트를 돌리며 공개된 특허 출원 하나를 검토하고 의견제출통지서 초안(docx, html)을 만듭니다. 글자 추출, 공보 받기, 단락 고르기, 인용문 원문 대조, 문서 조립은 코드가 하고, 구성 나누기와 검색과 판단만 Codex 가 합니다.

## 쓰기 전에
- 이미 공개된 출원만 넣으세요. 넣은 글은 Codex 를 거쳐 OpenAI 서버로 전송됩니다. 소속 기관의 규정 확인은 본인 책임입니다.
- 이 폴더를 OneDrive, Google Drive 같은 동기화 폴더에 두지 마세요.
- 도구는 로그인 정보와 API 키를 읽거나 묻지 않습니다. Codex 프로그램에 본인 계정으로 로그인한 상태를 그대로 씁니다.
- 공보는 patents.google.com 에서 한 건씩, 2초 넘는 간격으로 받습니다. 검색 페이지는 긁지 않습니다.

## 설치 (Windows)
1. [Python](https://www.python.org/downloads/windows/) 3.10 이상을 설치합니다. 설치 화면에서 Add python.exe to PATH 를 켭니다. 다른 패키지는 필요 없습니다.
2. Codex 프로그램을 설치하고 본인 계정으로 로그인합니다.
3. 이 저장소를 내려받아 풉니다(초록색 Code 단추, Download ZIP).
4. `setup.bat` 을 두 번 눌러 점검합니다.
5. Codex 프로그램에서 이 폴더를 열고 「처음 설정해줘」 라고 말합니다.

macOS 는 3단계까지 같고 `setup.command` 를 엽니다.

## 쓰는 법
1. 출원 PDF 나 TXT 를 `input` 폴더에 넣습니다.
2. 채팅에 「input 폴더의 출원을 검토해줘. 공개된 출원이야」 라고 말합니다.
3. 청구항, 출원일, 우선일이 맞는지 확인해 줍니다. 명령을 실행해도 되는지 묻는 승인 창은 정상입니다. 내용을 보고 허용하세요.
4. 끝나면 `cases/<사건>/out/` 에 `notice.docx` 와 `notice.html` 이 생깁니다. docx 는 한글에서도 열립니다.
5. 중간에 멈췄으면 「이어서 해줘」 라고 말합니다.

## 결과 읽기
```
거절 초안              근거 단락이 원문 대조를 통과한 청구항
보류                  근거가 부족하거나 검사에 걸린 청구항. 사유가 참고사항에 있음
거절이유를 찾지 못함     정상 결과. 억지로 문헌을 채우지 않음
원문 대조 실패          Codex 가 적은 인용문이 공보에 글자 그대로 없음. 거절 근거로 쓰지 않음
```
- 공개일이 판단 기준일보다 빠르지 않은 문헌, 받지 못한 문헌은 인용되지 않고 사유가 남습니다.
- 모든 인용문과 단락번호를 원문에서 다시 보고, 문장과 결론은 담당자가 정합니다.

## 알려진 한계
- 글자가 없는 스캔 PDF 는 읽지 못합니다. 도면과 수식은 보지 않습니다.
- PDF 는 낱말 중간에서 줄이 바뀝니다. 통지서의 청구항 글에 어색한 띄어쓰기가 있을 수 있습니다.
- 외국 공보는 기계번역일 수 있습니다. 목록에 표시됩니다.
- 공보 전체가 아니라 고른 단락만 읽으므로 놓친 기재가 있을 수 있습니다.
- 선행문헌 검색은 Codex 의 웹 검색에 기댑니다. 「거절이유를 찾지 못함」 은 이 검색 범위에서 못 찾았다는 뜻이지 특허 가능하다는 뜻이 아닙니다. 직접 찾은 문헌 번호를 말하면 함께 대조합니다.
- 원문 대조는 `cases/<사건>/docs` 에 저장된 공보와 맞춰 봅니다. 이 파일이 손으로 바뀌면 대조 결과를 믿을 수 없습니다. 중요한 단락은 공보 원본에서 다시 보세요.
- 시험판입니다. 공개 출원 하나로 끝까지 돌려 보았고, 검색과 판단의 정확도는 검증하지 않았습니다.
- 의견서와 보정서 검토, 거절결정, 전자결재는 하지 않습니다.

## 자료 지우기
사건 자료는 이 폴더의 `cases` 와 `input` 에만 있습니다(git 에 올라가지 않음). 필요 없으면 그 폴더를 직접 지웁니다.

## 개발
`python3 -m unittest discover -s tests` 로 시험합니다. 상태 파일 형식은 `docs/STATE.md`, 절차는 `.agents/skills/patent-notice/SKILL.md` 에 있습니다.
폴더 안에 넣은 외부 코드는 `vendor/README.md` 에 적었습니다(pypdf, BSD-3-Clause / typing_extensions, PSF-2.0).
