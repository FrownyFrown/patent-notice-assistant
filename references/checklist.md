# 확인 목록

제공된 정리본 9장의 항목을 계산 가능 여부에 따라 나눈다.
code의 ok는 실제 계산한 결과만 의미한다. 나머지는 자동 승인이 아니다.

- code: 공개 확인 입력, 공개일과 기준일, 원문 인용 대조, 신규성 단일 문헌, 종속항 조합(3225, 3330, 5319).
- codex: 효과 검토 기록, 결합 동기와 차이점, 설계변경 두 조건, 주지관용 증거 유무(3307-3316, 3330-3331).
- user: 최초본과 보정본, 날짜와 공지예외 및 분할, 용어 해석과 실시예 한정, 독립항 전제부와 실제 종속관계(2419-2420, 3214-3219, 5302).
- user: 공지성, 전문과 초록 구별, 저해 교시와 다른 분야의 관련성, 사후적 고찰(3305-3306, 3327-3329, 3331, 5205).
- user: 실시가능, 배경기술, 뒷받침, 명확성, 시행령 요건과 오기 처리(2301-2426).
- user: 전항의 조문, 차이점, 문헌 순서와 근거 위치, 미조사 범위, 보정 시사 문구(5202, 5317-5320, 5343-5347).
- user: 통지서 다섯 칸인 대상 항, 거절 항과 조문, 거절이유를 찾지 못한 항, 구체적 이유, 참고사항(5337-5340).
- user: 중간서류, 최후 통지, 재심사와 거절결정은 지원 범위 밖이다(5321, 5350, 5365-5366, 5371-5372, 5405).
- user: 사실과 판단을 구별하고 초안의 최종 결론을 확인한다(5105).
